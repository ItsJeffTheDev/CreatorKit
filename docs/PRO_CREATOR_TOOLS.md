# CreatorKit Pro creator tools

The live AppDeploy app now includes a **Pro creator tools** workspace with six browser-based utilities:

- **Title studio:** five topic-based title drafts.
- **Hook builder:** an opening line with selectable tone.
- **Description builder:** editable description and chapter outline.
- **Hashtag organizer:** normalized hashtags from the topic and supplied keywords.
- **Thumbnail brief:** a compact visual brief focused on mobile readability.
- **Repurposing planner:** a long-form idea, two Short concepts, a community post, and a follow-up idea.

## Important limitations

These are rule-based drafts generated locally in the browser, not AI research, trend analysis, or YouTube API features. Users should verify facts, edit the text, and avoid misleading titles. The app starts with an empty workspace and does not seed demo records.

Pro checkout uses the Stripe Payment Link configured in the live app. Verify the link itself is configured for the intended 14-day trial with no payment method collected upfront and $4.99/month after the trial. Subscription entitlement enforcement is not represented as complete by these client-side tools.
